# Full ambition pass

Use this when the user says "think bigger" or "be ambitious", or when the idea clearly deserves more than the short pass in Step 3. Pick the one or two lenses that fit, not all three.

## Contents
- Which lenses fit
- Altitude: aim at the outcome
- Depth: work like the field's best
- Range: bring in other fields
- Outside check
- Output format

## Which lenses fit

| Lens | Use when | Skip when |
|---|---|---|
| Altitude | The work serves an outcome people care about beyond the task itself | Creative work that is its own end |
| Depth | The result should be excellent, not just done | Throwaway or one-off work |
| Range | The result must land with people, or the obvious field has run out of ideas | A narrow fix with one right answer |

## Altitude: aim at the outcome

Ask what the goal behind the goal is, then climb a three-rung ladder. Each rung is more ambitious than the one below it:

1. **Understand.** Understand the real situation instead of filling in a template.
2. **Decide.** Focus on the decisions that matter, and argue both sides of each.
3. **Replace.** Swap the usual ritual for a better mechanism, check it against past data, and run it alongside the current way.

A higher rung may need setup first, such as gathering data, connecting a tool or building a test. Name that setup in the plan. If a rung has no outside check that could prove it worked, step down one rung.

## Depth: work like the field's best

Go below the surface of the task to the raw data, the real tools and the actual problem. Use the instruments experts use, not just their vocabulary. Set an aggressive target and treat it as reachable. Test common beliefs against the raw data.

Answer four questions, then fold the answers into the plan:
1. What would a top professional do here that nobody asked for?
2. What is the rawest starting material?
3. Which specific methods and tools would they use?
4. What outside check would confirm the result is right?

## Range: bring in other fields

Restate the task's nouns as verbs. "A dashboard" becomes "monitoring, deciding, alerting", which shows which fields could help. Pick 2 or 3 relevant experts (for example a data analyst, an editor, a UX researcher or a security red-teamer). Borrow their actual methods and tools, not their tone. If subagents are available and the job warrants it, give each field its own subagent with its method.

## Outside check

Every ambitious suggestion ends with an independent judge and a pass condition, such as a failing test that turns green, a metric that crosses a stated threshold, or real data that confirms the result. Never grade your own work. A missed target reported with real numbers is fine. A faked result is not.

## Output format

Keep it short and fold it into the conversation, one item at a time:
1. The goal behind the goal, in one line.
2. The lenses chosen and skipped, each with a short reason.
3. The suggestion for each chosen lens.
4. What it needs (data, tools, access), each marked available or missing.
5. The outside check and its pass condition.

Then return to Step 4 of SKILL.md with the accepted suggestions as part of the idea.
